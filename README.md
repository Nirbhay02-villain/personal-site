# personal-site

Portfolio website of **Nirbhay Kumar**, Business Analyst.

- `index.html`: the portfolio (about, experience, skills, education, contact)
- `css/portfolio.css`: styles, including mobile layout and dark mode
- `assets/Nirbhay_Kumar_Resume.pdf`: the resume offered by the "Download resume" button

It is plain HTML and CSS with no build step, so it can be hosted on GitHub Pages directly
(Settings → Pages → deploy from branch, root folder).
